## Overview

DocChain solves the KYC redundancy problem in financial institutions. When a customer verifies their identity with one bank, every other participating bank can trust that verification cryptographically — without asking the customer to resubmit documents.

**Key features:**
- SHA-256 document hash anchoring on immutable Hyperledger Fabric ledger
- PKI-based identity management with X.509 certificates per organization
- Role-enforced smart contracts (user / signer / regulator)
- Verifiable credentials — cross-bank trust without raw document sharing
- Real-time regulator audit trail with Fabric transaction IDs
- Three separate portals: User/Signer frontend, Regulator dashboard, REST API

**Tech stack:** Hyperledger Fabric 2.5.7 · TypeScript Chaincode · Node.js/Express · MongoDB · React · MUI · Docker

## Prerequisites

### 1. Install Docker

```bash
# Ubuntu / WSL2
sudo apt update
sudo apt install -y docker.io docker-compose-plugin

# Add current user to docker group (avoids sudo)
sudo usermod -aG docker $USER
newgrp docker

# Verify
docker --version          # 20.x+
docker compose version    # 2.x+
```

### 2. Install Node.js 18

```bash
curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
sudo apt install -y nodejs

# Verify
node --version    # v18.x.x
npm --version     # 9.x.x
```

### 3. Install Hyperledger Fabric Binaries

```bash
# Download Fabric 2.5.7 binaries + Docker images
curl -sSL https://bit.ly/2ysbOFE | bash -s -- 2.5.7

# Add binaries to PATH — add this to ~/.bashrc for persistence
export PATH=$PATH:$HOME/fabric-samples/bin
export FABRIC_CFG_PATH=$HOME/fabric-samples/config

# Verify
peer version          # 2.5.7
configtxgen --version # 2.5.7
cryptogen version     # 2.5.7
```

### 4. WSL2 Hostname Setup (Windows only — do once)

```bash
# Add service hostnames to /etc/hosts
echo "127.0.0.1 peer0.banka.com" | sudo tee -a /etc/hosts
echo "127.0.0.1 peer0.bankb.com" | sudo tee -a /etc/hosts
echo "127.0.0.1 peer0.regulator.com" | sudo tee -a /etc/hosts
echo "127.0.0.1 orderer.example.com" | sudo tee -a /etc/hosts

# Verify
grep -E "banka|bankb|regulator|orderer.example" /etc/hosts
```

> ⚠️ **WSL restart note:** These entries may disappear after WSL restarts. Re-add them if you see connection errors after restarting your PC. See [After a PC Restart](#after-a-pc-restart).

## Installation

### Step 1 — Clone the repository

```bash
git clone <repository-url>
cd decentralized-kyc
```

### Step 2 — Set up Fabric PATH (every new terminal session)

```bash
export PATH=$PATH:$HOME/fabric-samples/bin
export FABRIC_CFG_PATH=$HOME/fabric-samples/config
```

> **Tip:** Add both lines to `~/.bashrc` so they persist across sessions:
> ```bash
> echo 'export PATH=$PATH:$HOME/fabric-samples/bin' >> ~/.bashrc
> echo 'export FABRIC_CFG_PATH=$HOME/fabric-samples/config' >> ~/.bashrc
> source ~/.bashrc
> ```

### Step 3 — Start MongoDB

```bash
docker run -d \
  -p 27017:27017 \
  --name docchain-mongo \
  mongo:7

# Verify it's running
docker ps | grep mongo
```

### Step 4 — Configure backend environment

```bash
cp backend/.env.example backend/.env
# OR create it manually:
cat > backend/.env << 'EOF'
PORT=5000
NODE_ENV=development
CLIENT_ORIGIN=http://localhost:5173,http://localhost:5174

MONGO_URI=mongodb://127.0.0.1:27017/docchain

JWT_SECRET=your-super-secret-jwt-key-change-this
JWT_EXPIRES_IN=8h

RATE_LIMIT_WINDOW_MS=900000
AUTH_RATE_LIMIT_MAX=20
PIN_RATE_LIMIT_MAX=30

FABRIC_MOCK=false
FABRIC_CHANNEL_NAME=kycchannel
FABRIC_CHAINCODE_NAME=kyc-contract
FABRIC_CONNECTION_PROFILE=./src/config/connection-profile.json
FABRIC_WALLET_PATH=./wallet
FABRIC_MSP_ID=BankAMSP
FABRIC_ADMIN_USER=bankA-admin
FABRIC_ADMIN_PASSWORD=adminpw

MAX_UPLOAD_MB=10

SEED_REGULATOR_EMAIL=regulator@docchain.local
SEED_REGULATOR_PASSWORD=Regulator@123
SEED_REGULATOR_NAME=Regulator
EOF
```

### Step 5 — Install backend dependencies

```bash
cd backend
npm install
cd ..
```

### Step 6 — Install frontend dependencies

```bash
# Signer frontend
cd signer-frontend
npm install
cd ..

# Regulator dashboard
cd regulator-dashboard
npm install
cd ..
```

## Testing the Full Flow

Once all 4 services are running, test the complete KYC lifecycle:

### 1. Register a customer
- Open `http://localhost:5173`
- Click Register → fill name, email, password, PIN → role: **User**

### 2. Upload a KYC document
- Login as the user
- User Dashboard → Upload Document
- Select a PDF or image file, give it a title
- Submit → backend hashes the file and writes to blockchain

### 3. Register a KYC officer
- Open a new browser tab → `http://localhost:5173/register`
- Register with role: **Signer**

### 4. Approve the document
- Login as the signer
- Signer Dashboard → Pending Documents
- Click the document → Review → Approve → enter PIN
- Transaction written to blockchain, credential issued

### 5. Verify as regulator
- Open `http://localhost:5174`
- Login as regulator
- Overview dashboard shows updated statistics
- Audit Trail shows all actions with Fabric transaction IDs
- All Documents shows the approved document

### 6. Verify document hash
- `http://localhost:5173` → Verify tab → enter document ID
- System compares SHA-256 hash on blockchain vs file → shows authentic/tampered

## Network Management

```bash
cd fabric-network

./network.sh up      # Start network + deploy chaincode
./network.sh down    # Stop containers, remove volumes
./network.sh reset   # Full wipe (crypto + artifacts + volumes)
./network.sh status  # Show container/channel/chaincode status
```

### After reset — re-run these steps:

```bash
# 1. Re-import wallet identities (crypto was regenerated)
cd backend
node scripts/setupWallet.js

# 2. Re-seed regulator (MongoDB may be wiped too if you reset it)
npm run seed

# 3. Re-register your test accounts (blockchain state is fresh)
```

## After a PC Restart

WSL2 sometimes loses `/etc/hosts` entries and Docker containers stop. Run this checklist:

```bash
# 1. Check /etc/hosts
grep -E "banka|bankb|regulator|orderer.example" /etc/hosts

# If missing, re-add:
echo "127.0.0.1 peer0.banka.com peer0.bankb.com peer0.regulator.com orderer.example.com" \
  | sudo tee -a /etc/hosts

# 2. Start MongoDB if stopped
docker start docchain-mongo

# 3. Bring network back up
cd fabric-network
./network.sh up

# 4. Re-import wallet (if crypto was wiped)
cd ../backend
node scripts/setupWallet.js

# 5. Start backend + frontends (terminals 2, 3, 4 as above)
```

## Common Issues

### "peer0.banka.com: connection refused"
```bash
# Check /etc/hosts has the entries
grep banka /etc/hosts
# If missing, re-add (see WSL2 Hostname Setup)
```

### "No valid responses from any peers"
```bash
# Check Fabric containers are running
docker ps | grep -E "peer|orderer"
# If stopped, restart network
cd fabric-network && ./network.sh up
```

### "Identity not found in wallet"
```bash
cd backend
node scripts/setupWallet.js
# Then restart backend
```

### "Cannot connect to MongoDB"
```bash
docker start docchain-mongo
docker ps | grep mongo
```

### "ENDORSEMENT_POLICY_FAILURE"
The transaction was endorsed by only 1 peer but the policy requires majority (2/3). Check `connection-profile.json` has all 3 peers listed under the `channels.kycchannel.peers` section with `"endorsingPeer": true`.

### "context deadline exceeded" on peer join
```bash
# Peers need more time to start — wait 15s and retry
sleep 15 && ./network.sh up
```

### Chaincode container not starting (exit 127)
```bash
# Rebuild and redeploy chaincode
cd fabric-network/chaincode/kyc-contract
npm run build
cd ../..
# Then bump CC_VERSION in network.sh and run ./network.sh up
```

### After `network.sh reset` — stale MongoDB documents
Documents in MongoDB reference old blockchain state. Either:
- Drop the docchain database: `docker exec -it docchain-mongo mongosh --eval "db.getSiblingDB('docchain').dropDatabase()"`
- Or re-seed: `cd backend && npm run seed`

## Environment Variables Reference

| Variable | Description | Default |
|----------|-------------|---------|
| `PORT` | Backend server port | `5000` |
